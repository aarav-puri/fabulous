What Fabulous
helps you decide.

From the first design choice to the final mobile check, the skill gives the agent concrete guidance instead of a generic aesthetic prompt.

01 / DIRECTION

Visual identity

Set a point of view for type, color, imagery, layout, and motion before writing components.

02 / SYSTEM

Design tokens

Keep spacing, colors, surfaces, borders, and reusable UI consistent across the product.

03 / EXPERIENCE

UX and accessibility

Plan the primary action, interaction states, keyboard support, contrast, and useful feedback.

04 / DISCOVERY

Component research

Use 21st MCP to find a relevant pattern, then adapt it instead of shipping demo styling.

05 / ASSETS

Purposeful visuals

Use Higgsfield MCP for original visual assets when the placement, crop, and purpose are clear.

06 / REVIEW

Final quality check

Inspect hierarchy, readable type, responsive layout, accessibility, and visual polish.

Install with npx skills

Run this command to install Fabulous from GitHub:

npx skills add aarav-puri/fabulous --skill fabulous

The skill is named fabulous. For a global install, add -g. The command installs the skill; it does not configure external MCP servers.

Connect the resources

Install Frontend Design and UI/UX Pro Max, then connect 21st MCP and Higgsfield MCP. Confirm each resource is visible to your agent.

How do I make my repository installable?

Put SKILL.md in skills/fabulous/ (or at the repository root), keep the YAML frontmatter with name: fabulous and a description, and push the repository to GitHub. The command above installs it from this repository. This is an install through the open skills CLI, not a new npm package named Fabulous.

Set up UI/UX Pro Max
npx ui-ux-pro-max-cli init --ai <your-agent>

Use an agent name supported by the current UI/UX Pro Max CLI.

Connect 21st MCP
npx @21st-dev/cli@latest init --client <your-agent>

Select the client that matches your coding agent, then confirm the 21st MCP tools appear.

Connect Higgsfield MCP

Follow the Higgsfield MCP setup for your coding agent and confirm its visual-generation tools appear before using Fabulous.

From brief
to final polish.

Fabulous turns the resources into one coherent process instead of four disconnected tools.

01 / Understand

Read the product

Identify the audience, primary task, content, constraints, and existing visual language.

02 / Direct

Choose a point of view

Set typography, color, layout, spacing, motion, and imagery rules before coding.

03 / Systemize

Build the foundation

Turn the direction into reusable tokens, components, states, and responsive behavior.

04 / Discover

Use 21st MCP

Find components only when they fit, then adapt them to the project instead of preserving demo styling.

05 / Create

Use Higgsfield MCP

Generate visuals only when their placement, crop, contrast, and purpose are already clear.

06 / Critique

Fix what feels unfinished

Review hierarchy, accessibility, responsiveness, interactions, and consistency before finishing.
